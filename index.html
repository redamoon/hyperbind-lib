🎹 HyperBind

Keyboard Binding Library for Modern Web Applications

HyperBindは、モダンなWebアプリケーションでキーボードショートカットを簡単に実装するためのライブラリです。

React、Vue、VanillaJSの各フレームワークに対応しています。以下のデモアプリケーションで実際の動作を確認できます。

🌐
Native Example
VanillaJS（純粋なJavaScript）で実装されたデモアプリケーション。フレームワークを使わずにキーバインド機能を実装する例を提供します。
VanillaJS
⚛️
React Example
Reactフックとコンポーネントを使用した完全なデモアプリケーション。受注伝票入力、フォーム入力、カスタムキーバインド管理などの実用例を提供します。
React
💚
Vue Example
Vue 3のComposablesとコンポーネントを使用したデモアプリケーション。Vue 3のComposition APIでキーバインド機能を実装する例を提供します。
Vue 3
