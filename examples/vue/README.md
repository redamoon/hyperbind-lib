# HyperBind Vue Demo

HyperBindライブラリのVue 3デモアプリケーションです。Vue 3のComposition APIを使用したキーバインドの実装例を提供します。

## 🚀 起動方法

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev

# ビルド
pnpm build
```

## 📁 プロジェクト構成

```
examples/vue/
├── src/
│   ├── App.vue              # メインアプリケーション
│   ├── components/          # コンポーネント
│   └── pages/               # ページコンポーネント
├── index.html               # エントリーポイント
└── vite.config.ts           # Vite設定
```

## 🎯 デモ機能

### 基本的なキーバインド

Vue 3のComposition APIを使用したキーバインドの実装例。

### フォーム入力

FormNavigatorコンポーネントを使用したフォーム入力の例。

### カスタムキーバインド管理

useCustomKeybinds Composableを使用したカスタムキーバインド管理の例。
